# Retail_Sales_Analysis_Excel_Project
This project simulates a real-world scenario of a marketing analyst using Excel to evaluate customer purchase data. The aim is to extract insights using Conditional Formatting and key Excel functions.

## 📁 Project Structure

The workbook contains the following sheets:

1. **Raw_Data** – Original dataset with customer purchase information (Customer ID, Product Category, Purchase Date, Revenue, Age, Region)
2. **Sales_Highlight** – Highlights purchases with revenue > $500 using Conditional Formatting
3. **Monthly_Trends** – Highlights revenues that match the average using the `AVERAGE` function
4. **Region_Summary** – Uses the `SUMIFS` function to summarize revenue by region

## 🎯 Project Objective

To identify sales trends and provide insights through visual cues and function-based aggregation:
- Highlight high-performing sales
- Analyze and visualize revenue distribution over time
- Understand regional sales performance

## ✅ Key Excel Features Used

- **Conditional Formatting**
- **Functions Used**: `SUMIFS`, `AVERAGE`
- **Data Organization** using clear, separate sheets for each analysis goal

- Microsoft Excel
- Excel Functions & Formulas
- Conditional Formatting Rules
